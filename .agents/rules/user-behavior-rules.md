# Aturan Utama: Kepatuhan Penuh Terhadap Perintah User

1. **Kerjakan HANYA yang Diminta**:
   - Kerjakan secara presisi hanya apa yang diperintahkan secara eksplisit oleh user.
   - Dilarang keras menambahkan fitur, kode, back-end, efek tambahan, atau struktur yang tidak diminta oleh user (jangan nambah-nambahin).
   - Dilarang mengurangi, melewatkan, atau menghapus spesifikasi yang diminta oleh user (jangan ngurang-ngurangin).

2. **Konteks UI / Front-end**:
   - Jika user meminta UI, buat murni UI sesuai arahan visual dan fungsional yang diberikan.
   - Jangan berasumsi menambahkan backend, database, logika bisnis berlebihan, suara, atau fitur lain jika tidak diperintahkan.

3. **Disiplin Eksekusi**:
   - Jangan bertindak asal-asalan.
   - Ikuti instruksi langkah demi langkah secara disiplin dan akurat.
